Design Reference

This website is to be refined into a portfolio for the author, Jack Moyen. This is to be sent to all potential fields that it is needed for. Currently, there are a few empty, unneeded boxes left as decoration for the time being, and to be filled with content later.


All content images on the site are links which the user can click on to see more information.


For mobile screens, the site condenses as best it can, with the navbar becoming especially useful. Switching the main content from a grid to a flexbox allows for a "ladder" presentation instead of the previous grid.
